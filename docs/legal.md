# HEXFORGE Legal, Ethical & Safety Framework (PD-1..PD-12, Part 25)

## 1. Scope & Offline-Only Commitment
- **Personal, Private, Offline Games Only (`PD-1`, `PD-5`)**: HEXFORGE is engineered exclusively for inspecting, backing up, and modifying offline, single-player games owned by the user on their own personal Android device for educational, accessibility, preservation, and private experimentation purposes.
- **Zero Online/Competitive Interference**: Module `M6 Gatekeeper` is a structural, non-bypassable policy gate. Known online, competitive, multiplayer, and server-authoritative titles are refused with an explicit bilingual explanation.
- **No Piracy (`PD-4`)**: HEXFORGE never hosts, bundles, or redistributes copyrighted game binaries, APKs, OBBs, or unlocked assets. Patch packs and recipes contain instructions and offsets only, executed locally against the user's own installed copy.
- **No Anti-Cheat Evasion (`PD-11`)**: HEXFORGE does not build stealth or online anti-cheat evasion tools.

## 2. Store & Regional Ecosystem Awareness
- **Google Play & Iranian App Stores (Cafe Bazaar, Myket)**: Local billing-emulation adapters (`P-IAB`, `P-IAB-IR`) are documented for offline single-player compatibility testing, educational reverse-engineering, and user-owned offline preservation. Iranian and international independent developers' livelihoods matter; Gatekeeper and the Oracle mentor refuse requests targeting live server-side store economies, multiplayer leaderboards, or real-money transactions.
- **User Responsibility**: By accepting the first-launch notice, the user acknowledges responsibility for compliance with local laws and applicable software terms.

## 3. Privacy & Reversibility (`PD-7`, `PD-10`)
- **Zero Telemetry**: No analytics, crash trackers, or third-party data collection exist in HEXFORGE.
- **Direct User-Keyed AI**: When configured, the Oracle mentor communicates directly with Google's Gemini endpoint using the user's own Keystore-protected API key.
- **Vault Reversibility**: Mutating operations back up original artifacts to `M12 Vault` with SHA-256 verification before any bytes are altered.
